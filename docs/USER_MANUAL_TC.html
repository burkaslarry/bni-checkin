EventXP 活動管理系統 — 使用者手冊（繁體中文）

版本：1.0 · 適用對象：社群或商會和活動管理成員，如 BNI Anchor

一、系統簡介

EventXP 活動管理系統（EventXP）專為社群或商會設計，提供：

  • QR Code 簽到：會員與嘉賓掃描 QR Code 即可完成簽到
  • 即時報表：出席人數、準時／遲到／缺席一目了然
  • 嘉賓管理：預先匯入嘉賓名單，簽到時可快速選擇
  • CSV 匯出：活動結束後匯出簽到記錄，方便後續跟進

三、活動前準備（管理員）

3.1 建立活動與 QR Code

  1. 開啟管理後台 → 點選「新增活動和二維碼」
  2. 填寫活動名稱、活動日期
  3. 設定登記開始時間；系統會自動計算其他時段
  4. 點選「建立活動」，再點選「下載 PDF」
  5. 列印 PDF，放置於接待處供來賓掃描

3.2 匯入嘉賓名單（選用）

管理後台 → 匯入 → 選擇嘉賓，上傳 CSV。若未填活動日期，系統會自動帶入目前最新活動的日期。

四、現場簽到流程

4.1 會員簽到

掃描 QR Code → 選擇「會員」→ 下拉選單選擇姓名 → 點選「簽到」。

4.2 嘉賓簽到

掃描 QR Code → 選擇「來賓」→ 已登記則從下拉選單選擇；未登記則「手動輸入」姓名與專業領域後簽到。專業領域請務必填寫正確。

五、管理後台功能

5.1 活動管理

可查看目前活動、清除活動與簽到。建立新活動不會刪除舊活動。

5.2 管理員手動輸入（補簽）

管理後台 → 手動輸入 → 選擇嘉賓，填寫姓名、專業領域、邀請人。嘉賓名單僅顯示目前活動的嘉賓。

5.3 簽到記錄與 CSV 匯出

管理後台 → 簽到記錄 & 匯出 → 匯出 CSV。CSV 含姓名、專業領域、類別、出席狀態（準時／遲到／缺席）、簽到時間。匯出時系統會將出席狀態寫入後端資料庫。

六、報表頁面

網址：https://bni-anchor-checkin.vercel.app/report

可查看即時出席統計、會員／嘉賓比例、出席與缺席名單。

七、常見問題

  • 建立新活動後舊資料會不見嗎？ 不會，僅新增活動。
  • 嘉賓名單空白？ 請確認已為目前活動匯入嘉賓或設定活動日期。
  • 匯出 CSV 會寫入資料庫嗎？ 會，目前活動的出席狀態會一併寫入。
  • 準時與遲到如何區分？ 依活動設定的「準時截止」時間判斷。

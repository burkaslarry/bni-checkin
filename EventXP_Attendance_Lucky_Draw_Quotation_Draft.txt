PROJECT OVERVIEW

InnovateXP Limited proposes to provide an EventXP Attendance System and Lucky Draw System for the Client's upcoming event, expected to support approximately 600-700 participants.

EventXP is a mobile-first event check-in and activity intelligence platform designed for Hong Kong event organisers, member communities, business networking groups, conferences, seminars and corporate events. The system helps organisers replace manual paper check-in and spreadsheet handling with QR code / digital attendance tracking, real-time attendance monitoring, guest list management and lucky draw operation support.

For this event, the proposed solution focuses on technical system delivery and event operation support. Website design, campaign creative direction and full visual branding are expected to be handled separately by the Client's branding / design vendor where applicable.

The proposed technical solution focuses on three operational goals:

1. Faster and more organised guest check-in for 600-700 participants.
2. A reliable lucky draw workflow using checked-in participant data.
3. Optional onsite manpower support to assist the event team during live operation.


SCOPE OF SERVICES

1. Event Attendance System Setup

- EventXP event workspace setup for one event.
- Guest / participant list import based on the final Excel / CSV file provided by the Client.
- Digital attendance database setup for approximately 600-700 participants.

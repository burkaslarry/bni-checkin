# BNI Anchor 簽到系統 — 使用者手冊（繁體中文）

**版本**：1.0  
**適用對象**：BNI Anchor Chapter 會員、嘉賓、管理員

---

## 一、系統簡介

BNI Anchor 簽到系統（EventXP）專為 BNI 分會設計，提供：

- **QR Code 簽到**：會員與嘉賓掃描 QR Code 即可完成簽到
- **即時報表**：出席人數、準時／遲到／缺席一目了然
- **嘉賓管理**：預先匯入嘉賓名單，簽到時可快速選擇
- **CSV 匯出**：活動結束後匯出簽到記錄，方便後續跟進

## 三、活動前準備（管理員）

### 3.1 建立活動與 QR Code

1. 開啟 **管理後台** → 點選「新增活動和二維碼」（或前往 QR 產生頁面）
2. 填寫 **活動名稱**、**活動日期**
3. 設定 **登記開始時間**；系統會自動計算「活動開始」「準時截止」「結束時間」
4. 點選 **「建立活動」**，再點選 **「下載 PDF」**
5. 列印 PDF，放置於接待處供來賓掃描

**提示**：建議將簽到網址加入手機書籤，方便現場使用。

### 3.2 匯入嘉賓名單（選用）

若活動前已有嘉賓名單：

1. 進入 **管理後台** → **匯入**
2. 選擇 **嘉賓**，上傳 CSV（欄位：姓名、專業領域、電話、邀請人、活動日期）
3. 若未填活動日期，系統會自動帶入「目前最新活動」的日期
4. 完成匯入後，簽到頁面「來賓」可從下拉選單選擇已登記嘉賓

## 四、現場簽到流程

### 4.1 會員簽到

1. 掃描現場 QR Code（或開啟簽到網址）
2. 選擇 **「會員」**
3. 在下拉選單中選擇自己的姓名
4. 點選 **「簽到」**

### 4.2 嘉賓簽到

1. 掃描 QR Code
2. 選擇 **「來賓」**
3. 若已預先登記：在 **「已登記來賓」** 下拉選單中選擇姓名後簽到  
4. 若未登記：選擇 **「手動輸入」**，填寫姓名與專業領域（及邀請人）後簽到

**重要**：專業領域為 BNI 媒合與後續跟進的依據，請務必填寫正確。

## 五、管理後台功能

### 5.1 活動管理

- **查看目前活動**：日期、登記／開始／準時截止時間
- **清除活動與簽到**：僅在需要「重新開始」時使用；**建立新活動不會刪除舊活動**

### 5.2 管理員手動輸入（補簽）

當嘉賓無法自行掃碼時，可由管理員代為輸入：

1. 進入 **管理後台** → **手動輸入**
2. 選擇 **嘉賓**，填寫姓名、專業領域、嘉賓身份（嘉賓／VIP／講者）、邀請人
3. 可選擇 **單筆** 或 **批次** 簽到（批次可勾選多名已列出的嘉賓）
4. **嘉賓名單**：僅顯示「目前活動」的嘉賓，不會顯示過往活動或未來活動的嘉賓

### 5.3 簽到記錄與 CSV 匯出

1. 進入 **管理後台** → **簽到記錄 & 匯出**
2. 檢視目前活動的簽到列表
3. 點選 **「匯出 CSV」** 下載檔案  
4. CSV 內容包含：姓名、專業領域、類別（會員／嘉賓）、出席狀態（準時／遲到／缺席）、簽到時間  

**說明**：匯出 CSV 時，系統會同時將「目前活動」的出席狀態（準時／遲到）寫入後端資料庫，供報表與歷史查詢使用。

## 七、匯入功能說明

- **會員匯入**：用於更新或批次建立會員名單（姓名、專業領域等）
- **嘉賓匯入**：用於活動前批次建立嘉賓名單；未填活動日期時，自動帶入「目前最新活動」的日期

## 八、常見問題

**Q：建立新活動後，舊活動的資料會不見嗎？**  
A：不會。建立新活動只會「新增」一筆活動，不會刪除舊活動。報表與匯出以「目前最新活動」為準。

**Q：嘉賓名單顯示空白？**  
A：請確認已為「目前活動」匯入嘉賓，或該活動日期已設定；手動輸入與簽到頁的嘉賓列表僅顯示「目前活動」的嘉賓。

**Q：匯出 CSV 後，資料會寫入資料庫嗎？**  
A：會。匯出 CSV 時，系統會將目前活動的出席狀態（準時／遲到等）一併寫入後端，供報表與歷史查詢使用。

**Q：如何區分「準時」與「遲到」？**  
A：依活動設定的「準時截止」時間判斷；簽到時間早於該時間為準時，否則為遲到。
